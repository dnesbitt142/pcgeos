# Historical records, preserved without rewriting

These reports were copied from the prior full-product, PMDIAG1, PMDIAG2,
TrueType-fix and Perf-KR01-fix packages. They include historical absolute build
paths, hashes, warnings and then-current verification statuses. No binaries,
font files or executable font data are stored here.

They are evidence of earlier work, not results of a new full-product build or
guest boot. Some "failure not yet identified" fields were superseded by later
fixes. Use `../STATUS.md` for the current summary and `../VALIDATION.md` for the
checks actually performed while preparing this handoff.
